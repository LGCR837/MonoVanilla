MonoVanilla 兼容动画包 · 演示

Message / Notification 是命令式 API。MVAnim.notification() 生成玻璃拟态卡片：半透明面 + 背景模糊、按色调描边与图标、底部一条随自动消失而收缩的倒计时条；堆叠时兄弟项 FLIP 平滑位移。

MVAnim.flipGroup(el, mutate)：在容器内做增删 / 重排前先快照子元素位置，变更后倒置 + 重排，兄弟项平滑位移（等价 Vue TransitionGroup 的 move；零 CSS 依赖、纯内联 transition，Chrome 38 可用）。tabs 切换、卡片重排、拖拽落位、虚拟列表都能用。底层 flipPre / flipPost 可单独调用。

13. Tooltip · 方向自适应浮层（命令式）

MVAnim.tooltip(anchor, text, opts)：相对锚点定位、水平居中、视口放不下自动上下翻转；淡入淡出 180ms（WAAPI opacity，Chrome 38 可用），pointer-events:none 不挡交互。返回 { el, close() }，悬停显示、移开关闭。opts：gap（间距）、zIndex。

MVAnim.sequence(steps, opts)：按序执行动画步骤。步骤可以是 number（等待毫秒）、function(next)（调用 next 推进，或返回数字表示等待），便于把多段动效编排成流水线；返回 { cancel() }。配合 MVAnim.tokens（ease / duration）可统一节奏。

18. 组件级 · Popover / 图片渐显

带箭头、自动上下翻转、点外部 / Esc 关闭

MVAnim.popover(anchor, content, opts)：带方向箭头的浮动面板，自动上下翻转 + 水平居中 + 边缘夹取；点外部 / Esc 关闭，返回 { open, close, toggle, isOpen }。MVAnim.imageReveal(img, opts)：图片 onload（或已 complete）时做 opacity + 背景模糊的渐显，reduced-motion 下直接显示。opts：gap / zIndex / content（字符串或元素）/ duration / blur。

19. 进度条 / 环 · setProgress（命令式）

同一 setProgress 驱动条形（scaleX）与圆环（stroke-dashoffset）

MVAnim.setProgress(el, value, opts)：value 0–100。普通元素按 scaleX 填进度条；<circle data-pathlength> 圆环按 stroke-dashoffset 走线；reduced-motion 直接到位。返回 { cancel }；从上一次显示值补间到目标。

20. 通用过渡 · fadeIn / fadeOut / slideUp / slideDown

卡片
可对任意元素做淡入 / 淡出 / 上滑 / 下滑，无需命名 CSS 状态。

MVAnim.fadeIn / fadeOut / slideUp / slideDown(el, opts)：基于内联 transition 的通用进出场（Chrome 38 可用，不依赖命名 CSS 状态）。opts：duration / easing / translateY / scale / distance / onDone；返回 { cancel() }。

21. 折叠面板 · accordion（命令式）

纯函数式动效系统：核心过渡、FLIP、命令式堆叠、组件级过渡，均 ES5 / Chrome 38 安全。
默认单开（single），传 single:false 可让多个面板同时展开。
触发器带 role=button / aria-expanded / aria-controls，面板 role=region / aria-hidden，支持键盘 Enter / 空格。

MVAnim.accordion(wrapper, opts)：管理 .acc-item（内含 [data-acc-trigger] 与 [data-acc-panel]），展开用内置 expand/collapse 高度补间 + ARIA 状态；opts：single（默认 true）/ duration / openFirst / onOpen / onClose。返回 { open, close, toggle, isOpen, items }。

22. 目录高亮 · scrollSpy（命令式）

概览 架构 性能 部署

概览

向下滚动右侧内容，左侧目录随视口自动高亮。底层用 IntersectionObserver，Chrome 38 无 IO 时回退到 scroll + rAF。

架构

模块化的命令式 API，无构建、无框架依赖，可挂在任意元素上。每一段过渡都可插拔钩子。

性能

只动 transform / opacity / filter，优先合成层，避免触发布局重排。FLIP 与进度条都走 rAF 补间。

部署

拷贝 monovanilla-anim.js + monovanilla-animations.css 即可，暴露 window.MVAnim，按需在页面初始化时调用各能力。

MVAnim.scrollSpy(nav, sections, opts)：观察 sections、按视口位置高亮 nav 中 data-target 对应项；opts：root（可滚动容器）/ rootMargin / threshold / className（默认 'on'）/ onEnter；返回 { disconnect() }。
